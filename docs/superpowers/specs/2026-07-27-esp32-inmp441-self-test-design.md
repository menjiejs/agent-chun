# ESP32 INMP441 麦克风自检设计

## 目标

提供一个与现有 TTS 扬声器固件隔离的最小自检固件，用于确认经典
ESP32-D0WDQ6 能从已经接好的 INMP441 麦克风持续获得有效音频数据。

## 硬件与接线

目标开发板使用 PlatformIO 的 `esp32dev` 环境，串口当前识别为
`/dev/cu.usbserial-110`。INMP441 使用 3.3V 供电并选择左声道：

| INMP441 | ESP32 扩展板 |
| --- | --- |
| VDD | 3V3 |
| GND | GND |
| SCK / BCLK | D27 的 S |
| WS / LRC | D33 的 S |
| SD / DOUT | D32 的 S |
| L/R | GND |

麦克风不得连接 5V、VCC 或扩展板的可切换 V 电源排。

## 固件方案

新增独立的 PlatformIO 工程，不修改现有
`firmware/esp32-tts` 扬声器固件。自检固件配置 ESP32 I2S 接口为主机接收
模式，以 16 kHz 读取 INMP441 左声道的 32 位采样槽。

固件分块读取采样，去除直流偏置后计算一段窗口内的峰值和平均绝对幅度。
每约 200 ms 通过 115200 波特率串口输出：

- 当前采样是否成功；
- 数字音量值；
- 随音量变化的简易字符音量条。

自检不连接 Wi-Fi、不上传或保存录音、不播放音频，也不读取项目中的服务
密钥。

## 错误处理

- I2S 初始化失败时，串口显示明确错误并停止读取。
- 读取超时或读取失败时，串口显示错误，不把无效缓冲区当作音频。
- 长时间只有接近零的数值时，提示检查 VDD、GND、L/R 和三根 I2S 信号线。
- 数值持续接近满量程时，提示检查数据格式、声道选择或接线短路。

## 测试与验收

自动验证音量计算逻辑对静音、固定偏置和有变化的样本给出预期结果，并确认
`esp32dev` 固件能够编译。

实机验收步骤：

1. 将自检固件烧录到 `/dev/cu.usbserial-110`。
2. 打开 115200 波特率串口监视器。
3. 安静时观察到较低且相对稳定的音量值。
4. 对着麦克风说话或在附近拍手时，数字和音量条明显升高。
5. 连续观察约 30 秒，无 I2S 初始化失败、读取错误或开发板反复重启。

自检结束后可以重新烧录原有 `esp32-tts` 固件恢复扬声器功能。

## 暂不包含

- 录音文件生成或回放；
- 音频上传、语音识别或唤醒词；
- 麦克风和 MAX98357 同时运行；
- 自动增益、降噪或回声消除。
